# Generated data files

Everything here except `index.ts` and `product-links.json` is generated by the data pipeline
(area A): don't edit it by hand. Regenerate it with the scripts described in
[`scripts/CLAUDE.md`](../../../scripts/CLAUDE.md). The files are listed, with what makes and uses
each, in [`docs/ARCHITECTURE.md`](../../../docs/ARCHITECTURE.md#the-data-files-in-srclibdata).

`index.ts`, the server-side reader, belongs to the back end (area B): see
[`src/lib/api/CLAUDE.md`](../api/CLAUDE.md). It caches what it returns and shares it across
requests, so never mutate the result.
